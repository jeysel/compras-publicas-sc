Scaffold de dev (Vite) — nunca é servido em produção.

A home real é api/app/templates/home.html (Jinja2), renderizada pela API — essa é a única fonte de verdade de estrutura/HTML.

Fetches relativos (/api/v1/...) não resolvem aqui sem proxy (não configurado). Para testar contra dados reais, use docker compose --profile api up api -d --build e abra a página renderizada pela API.

Para iterar em um gráfico específico neste modo, troque data-page no <body> e/ou adicione manualmente os elementos que o chart espera (ver web/src/main.ts para o mapeamento page → render).
