# Ordem de leitura

Para quem vai implementar uma mudança neste repo — pessoa ou agente de IA —, a ordem
recomendada de leitura é:

1. [`docs/memory/constitution.md`](../memory/constitution.md): regras não-negociáveis.
2. [`docs/steering/compras-publicas.md`](compras-publicas.md): arquitetura em regime.
3. [`docs/specs/`](../specs/): specs numeradas, uma por mudança. A spec mais recente sobre
   um tema prevalece; as antigas ficam como histórico. Antes de criar uma spec, usar
   [`docs/specs/_template.md`](../specs/_template.md).

[`docs/specs/_tasks.md`](../specs/_tasks.md) é um template de tasks.md (tarefas com aceite
executável: comando + saída esperada), ainda em teste.

O backlog de épicos e histórias de usuário foi a matéria-prima das specs e hoje está
arquivado, ainda visível em [`docs/backlog-archived/`](../backlog-archived/).
