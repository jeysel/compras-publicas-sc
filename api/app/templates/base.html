Metodologia

Contratos com fl_aditivo_inconsistente = true têm divergência, acima de arredondamento, entre o valor de aditivo registrado na fonte (vl_aditado) e a variação calculada (vl_atual - vl_original) — sinal de qualidade de dado da fonte, não um erro de cálculo deste sistema (ver spec 013/014). Por padrão, esses contratos são excluídos das agregações de valor onde a granularidade do dado permite o filtro (ex.: escalada de custo). Quando a agregação já vem pronta de uma mart sem essa granularidade (ex.: série temporal), a exclusão ainda não é possível e fica registrada como pendência.

Contratos com fl_valor_suspeito = true têm valor (vl_original ou vl_atual) implausível para o objeto contratado — por exemplo, um contrato registrado com valor milhares de vezes maior que o valor atual do mesmo contrato. A investigação confirmou que se trata de erro de dado da fonte (portal/SICOP), não deste sistema. Por padrão, contratos com essa flag são excluídos das agregações de valor exibidas nos gráficos (ver spec 021 para o detalhe técnico completo, incluindo os padrões de corrupção identificados e a magnitude do problema no dataset).
